# 🚗 RideWise
### Smart Ride Booking Web Application

RideWise is a modern, full-stack ride booking web application designed to provide a seamless transportation experience. It allows users to securely register, book rides, manage bookings, and track ride history through a responsive and user-friendly interface.

---

## 📌 Project Overview

RideWise simplifies urban transportation by combining an intuitive frontend with a robust backend system.  
The application ensures secure authentication, efficient booking management, and responsive design across all devices.

This project demonstrates full-stack development using the MERN Stack (MongoDB, Express.js, React.js, Node.js).
